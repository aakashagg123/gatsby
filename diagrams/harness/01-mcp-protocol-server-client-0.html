A handshake, then normal work

Initialize, notify, list tools, call a tool

A notification has no id and gets no reply. A tool failure comes back as isError, not a protocol error.

Client → initialize
reply→
Server → result (version, capabilities, serverInfo)
Client → notifications/initialized
no reply→
Normal work begins
Client → tools/list
reply→
Server → {tools: [name, description, inputSchema]}
Client → tools/call (name, arguments)
reply→
Server → {content, isError}
