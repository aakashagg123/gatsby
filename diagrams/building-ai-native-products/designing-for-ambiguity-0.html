A funnel of intent

Narrow the meaning, leave the last step to the user

Each stage cuts down what the input could mean.

1User job
what they are trying to get done

Start here, not with the model.

2Opinionated start
defaults · examples · scope

Do not hand over a blank box.

3Open input
free text or voice

Ambiguous by nature.

4Model response
uncertain

Show sources and doubt.

5Check and correct
preview · edit · undo

Cheap to fix, easy to trust.

Feedback from corrections improves the starting point.
