The six patterns

Almost every everyday LLM use fits one of these six

Naming the pattern before you start typing is the difference between a prompt that lands and one that wanders.

A task on your desk
Which pattern?
1 · Draft-then-edit — model writes v0
2 · Summarize — long → short
3 · Translate — format, tone, language
4 · Extract — unstructured → structured
5 · Critique — get it torn apart
6 · Brainstorm — divergent options
