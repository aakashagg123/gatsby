Three families

What each can see, and what it costs

A model can only find patterns its shape allows.

Linear model

Sees: weighted sums, straight-line effects.
Needs: little data.
Explains: yes, weight by weight.
Best for: a first model, regulated decisions.

Trees and ensembles

Sees: if-then splits and interactions.
Needs: little preparation.
Explains: one tree yes, a forest no.
Best for: tables of rows and columns.

Neural network

Sees: almost any shape; learns its own features.
Needs: lots of data and compute.
Explains: hard.
Best for: text, images, audio.

Pattern "two scores with the same sign": linear 47.3% · tree 90.8% · small network 89.5%.
