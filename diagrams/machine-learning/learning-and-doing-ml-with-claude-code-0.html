Working with an agent

You hold the contract. The agent runs the loop.

An agent makes the loop fast. The checks keep the result true.

A check fails

Back to the loop, loudly. The agent fixes the cause, not the symptom.

All checks pass, with evidence

The command, the output and the log line come to you. You decide.

The agent can run hundreds of experiments. Each extra try is another chance for a lucky score.
