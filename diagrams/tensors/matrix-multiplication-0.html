Why batching pays

Same weights, more work per byte

Arithmetic intensity rises with the batch.

The shape rule

(m, k) × (k, n) → (m, n)
FLOPs = 2 × m × k × n
A batch reads the weights once.

One input is memory-bound

A matrix-vector product always does fewer than 1 FLOP per byte. A batch of 512 does about 205.

intensity assumes each matrix is read or written once, as in NVIDIA's guide
