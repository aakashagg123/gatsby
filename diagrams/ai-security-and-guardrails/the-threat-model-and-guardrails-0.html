Threat model

Four distinct attack shapes · four different countermeasures

"Guardrails" isn't one control — it's a layered defense, each layer against a specific attack.

Jailbreak

Talk the model out of its own trained refusals

→
Output classifiers

+ behavioural monitoring on the response stream

Injection

Hide commands in data the model reads

→
Untrusted-content handling

+ permissions in code, not in the model

Extraction

Pull training data, prompts, or weights out

→
Rate limits + watermarking

+ output-similarity monitoring

Poisoning

Corrupt what the model learns in the first place

→
Corpus provenance

+ anomaly detection on training data
