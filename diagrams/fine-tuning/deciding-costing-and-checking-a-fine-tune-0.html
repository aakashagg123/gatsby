The decision

Three questions before you tune

Each answer ends in an action.

1A behaviour problem

Where you start.

2Does a better prompt or retrieval fix it?
yes: do that

If no, go on.

3Is there a test that measures it?
no: build the test first

If yes, go on.

4Does the saving pay for the project at our volume?
no: do not tune

If yes, go on.

5Tune, then gate the release

Gain above the margin, general drop below the limit.

Example break-even: about 250,980 requests for a $2,000 project (invented prices).
