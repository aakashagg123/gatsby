Value gates

Three gates · pass all three or the AI destroys value

Answering "no" to any of them means the return on the AI investment turns negative.

A proposed use case
G1
Is doing this by hand slow or expensive today?
no ↴
Value destroyed. You paid for AI to solve a problem that didn't exist.
G2
Can the output be checked cheaply?
no ↴
Value destroyed. Checking costs as much as doing it by hand.
G3
Is being wrong sometimes acceptable?
no ↴
Value destroyed. One bad output outweighs every good one.
All three · Yes → value created

A real, funded win — the shape most successful genAI features share.
