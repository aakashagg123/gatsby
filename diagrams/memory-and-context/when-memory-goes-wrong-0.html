When it breaks

Four parallel failures from one memory store · each with a specific test

Not variants of "the model got it wrong" — each is a structural gap with a structural fix.

A memory store
Q · Stale?
Stale & wrong
Product acts confidently on outdated info · no signal that it's old
Fix: last-confirmed date · expiry · replace rule on the write path
Q · Crossed?
Leaked
One user's or tenant's data reaches another — the boundary that mattered most
Fix: user / tenant ID on every write · filter in the store before ranking
Q · Fixable?
Stuck
User can't see, correct, or delete — a wrong memory persists indefinitely
Fix: "what do you remember about me" screen · delete reaches summaries and indexes
Q · Planted?
Poisoned
Untrusted content writes a hostile instruction that acts in every later session
Fix: hold untrusted writes for confirmation · show sources · user review
