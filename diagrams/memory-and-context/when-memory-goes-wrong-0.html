When it breaks

Three parallel failures from one memory store · each with a specific mitigation

Not variants of "the model got it wrong" — each is a structural gap with a structural fix.

A memory store
Q · Stale?
Stale & wrong
Product acts confidently on outdated info · no signal that it's old
Fix: explicit freshness — last-confirmed date · expiry · periodic re-check
Q · Crossed?
Leaked
One user's or tenant's data reaches another — the boundary that mattered most
Fix: tenant / user ID stamped on every write · checked at every read
Q · Fixable?
Stuck
User can't see, correct, or delete — a wrong memory persists indefinitely
Fix: user-facing "what does this product remember about me" surface
