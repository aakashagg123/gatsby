Three scopes

Session · user · organizational · three metaphors, three risk levels

The boundary of the memory is the boundary of the promise. Name it before you spec it.

a sticky note
Session memory
Just this conversation
Lives only within one thread
Discarded when the session ends
Lowest-risk shape · still worth naming
a personal file
User memory
Across sessions · one person
Persists across separate visits
Ties data to one specific person
Needs consent · visibility · edit · delete
a shared handbook
Org memory
Shared across a whole team
Team-wide facts, preferences, decisions
Needs an owner keeping it accurate
"Who's inside the org" boundary is security-critical
