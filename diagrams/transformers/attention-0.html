Attention

A lookup that blends · four steps, one mask

Each token asks a question, every earlier token offers an answer, and the reply is a weighted mix.

1Project

Make three vectors per token: query Q, key K, value V.

2Score

Match each query with every key: Q·Kᵀ. A big number means a good match.

3Normalize

Divide by √d_k, hide later tokens, then softmax. Each row sums to 1.

4Blend

Multiply the weights by V. Each token gets a mix of what it matched.

The causal mask. Row 4 can weigh tokens 1 to 4. Tokens 5 and 6 have weight exactly 0, so a model cannot read the answer it is meant to predict.

Without the √d_k division, 8 random keys at d_k = 256 give a top weight of 0.92. With it, 0.34.
