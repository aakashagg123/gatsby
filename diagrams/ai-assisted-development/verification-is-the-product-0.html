The Stop-hook gate

The agent's word versus an exit code

The check runs when the agent tries to finish. Only a pass lets it stop.

Agent says "done"

A sentence. It may not have run the tests.

Stop hook runs the check

One command: tests, types, lint. Fast and deterministic.

Guards

stop_hook_active set: exit 0, no trap. After 8 blocks in a row Claude Code lets the agent stop.

Exit 0

The check passed. The agent may stop.

Exit 2 + message

The agent keeps working and sees the failure text.

Review then confirms the check tests the right thing, and that no test was weakened.
