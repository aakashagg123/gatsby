Two documents

A briefing for a capable stranger

The agent remembers nothing between sessions, so it needs both every time.

1Context file
always true · short

Build and test commands, traps. Under about 200 lines.

2Path rules and skills
loaded when relevant

Part-of-codebase rules and multi-step procedures.

3Spec for this task
goal · scope · constraint · check

The check is the part most often missing.

4Session starts, agent works

With the standing brief and the job card.

Imports organize a file but do not cut its context cost.
