Four nested controls

Each layer catches what the one above lets through

Only the last does not depend on how the agent words a command.

1Mode
the default posture

Manual · acceptEdits · plan · auto · dontAsk · bypass.

2Rules
deny, then ask, then allow

First match wins. A shell rule matches the text as written.

3Hooks
your code decides

Sees the real arguments and can block.

4Sandbox
the operating system enforces

Container, limited network, no secrets.

Rules are guardrails for honest mistakes. They are not a security boundary.
