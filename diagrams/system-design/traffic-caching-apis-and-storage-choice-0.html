A request passes four doors

The deeper it goes, the slower and costlier it gets

Each door tries to answer before the request goes deeper.

1CDN
a nearby copy

Static files, images, video segments.

2Load balancer
spread and health-check

Layer 4 is fast. Layer 7 can route by path.

3App servers
stateless

Any server can answer any request.

4Cache
memory

Cache-aside, write-through or write-back.

5Database
source of truth

Chosen by access pattern.

Design for most requests to stop at the first or second door.
