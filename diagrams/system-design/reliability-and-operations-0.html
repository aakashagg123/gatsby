Layers of defence

No layer is perfect, so each catches what the one above missed

A change or a fault meets four layers.

1Safe rollout
canary · flags · rollback

Limit what your own changes can break.

2Resilience patterns
timeout · breaker · shed load

Stop a small failure from spreading.

3Blast radius
cells · regions

Contain what does fail.

4Recovery
backups · failover · runbooks

Restore fast, and test the restore.

Recovery tools must not depend on the system that failed.
